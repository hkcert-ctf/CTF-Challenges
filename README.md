# HKCERT CTF Challenge

![HKCERT CTF](CTF_KV.png)


## Background
Internet technology will dominate the future world, but at the same time new cyber security challenges emerge. Through Technology Education (TechEd), we could foster and enhance students’ knowledge and interest in cyber security. Train up creative thinking and learn skills such as cryptography, programming concept, network forensics, etc. to deal with new challenges.

Hong Kong Computer Emergency Response Team Coordination Centre (HKCERT), Hong Kong Productivity Council (HKPC) and Digital Policy Office (DPO) jointly host the “HKCERT CTF Challenge” Contest to arouse the cyber security awareness of the education sector and encourage student problem solving with teamwork, creative thinking and cyber security skills via a fun game. Join now and get ready for the challenge!

## Description
This repository is to keep the challenges used in all previous competitions. The objective is to allow you to practice and learn. Please note that only source code is provided so you have set up the challenge in your environment by yourself.
